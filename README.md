# image-stock-3

Pictures, sounds, video and fonts for RoleForge (by DesZiDesu), served through jsDelivr.
The files live on the branches named media-* / cards-* (one branch per piece, each under jsDelivr's 50 MB limit).
They are written by RoleForge's release tools (tools/export-media.mjs); do not edit them by hand.
